- "«Анатомия Tor» (Anatomia di Tor / Onion Routing Anatomy)" (https://github.com/aleff-github/onion-routing-anatomy/tree/main/book/ru) — бесплатная книга с открытым исходным кодом о внутреннем устройстве протокола Tor: шифровании, построении цепочек, onion-сервисах и анализе трафика. Включает 20 практических лабораторных работ с Python, Docker и частной тестовой сетью Tor. Русская версия доступна в форматах PDF и EPUB. Лицензия GPL-3.0-or-later.
